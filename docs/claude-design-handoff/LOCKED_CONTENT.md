## 10. FAQ（`FAQSection.tsx`）— 11問。順序もそのまま

1. **`無料で使えますか？`**
   `はい。カメラでの円換算・通貨換算・翻訳・音声入力・読み上げ・買い物カレンダー・期間ごとの合計の確認は、無料版で回数の制限なくお使いいただけます。無料版では、同時に管理できる旅行が1件、1つの旅行につき10件まで保存できます。`

2. **`レートは自動で取得されますか？`**
   `いいえ。レートはご自身で入力していただく方式です。両替時のレートやカード決済のレートなど、実際にご自身が使うレートを入力できるため、感覚に合う金額で判断できます。旅行前に入力しておけば、現地ですぐ使えます。`

3. **`通貨記号は自動で判定されますか？`**
   `いいえ。事前に「USD→JPY」「KRW→JPY」のように換算モードを選んでいただく方式です。読み取りの精度と速度を優先した設計のため、数字の読み取りは安定して動作します。`

4. **`電波がない場所でも使えますか？`**
   `入力したレートでの円換算は端末内で計算するため、通信が不安定な場所でもそのままお使いいただけます。旅行前にレートを設定しておくと安心です。`

5. **`Proにすると何が変わりますか？`**
   `保存が無制限になり、複数の旅行を同時に管理できます。あわせて、カテゴリーでの絞り込み・カテゴリー別の分析・CSVエクスポートが使えます。カメラ・翻訳・音声・カレンダーなどの基本機能は無料版と同じです。`

6. **`カレンダーや分析は無料で使えますか？`**
   `買い物カレンダーと、期間ごとの合計・件数の分析は無料版でお使いいただけます。カテゴリー別の内訳・構成比の分析と、カテゴリーでの絞り込み、CSV書き出しがPro版の機能です。`

7. **`Proの料金はいくらですか？`**
   `月額 ¥500、年額 ¥4,000 です。年額は月あたり約 ¥333 になります。最新の価格はApp Storeの表示をご確認ください。`

8. **`保存したデータはどこにありますか？`**
   `保存した買い物の記録は、お使いの端末内に保存されます。詳しくはプライバシーポリシーをご確認ください。`

9. **`Proを解約したら、保存したデータは消えますか？`**
   `消えません。解約後も、それまでに保存した記録や旅行のデータは残ります。無料版の上限を超えている分については、新しく追加することができなくなります。`

10. **`解約はどこからできますか？`**
    `App Storeの購読管理から、いつでも解約できます。解約後も、購読期間が終わるまではPro版の機能をお使いいただけます。`

11. **`日本円から外貨への換算もできますか？`**

## 13. 端末モック内のテキスト（`PhoneFrame` の内側）— **完全凍結**

端末モックに表示されているテキスト・数字・UIラベルは、
**アプリの実装画面そのもの**であり、デザインの対象外。

- 旅行名: `ソウル旅行` / 通貨 `KRW` / レート `1 KRW = ¥0.11` / 予算 `¥30,000`
- 記録: `HERA BLACK CUSHION` `₩42,900`→`¥4,719` ほか3件
- 集計: 購入済み `¥12,760` / 候補 `¥4,719` / 残り予算 `¥17,240` / 保存 `4`件
- 翻訳デモ: `これのいちばん小さいサイズはありますか？` / `이것의 가장 작은 사이즈가 있나요?`

これらの数値は `src/components/mock/demoData.ts` で**計算により整合が取られている**
（残り予算 = 予算 − 購入済み合計）。過去に画面間で数字がずれる不具合があったため
1ファイルに集約された経緯がある。**個別に書き換えると再発する。**

また、`PhoneFrame` の `aria-label`（画面内容の説明文）も消さないこと。
