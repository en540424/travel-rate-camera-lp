# ブランドアイコン：reference と正式Webアセットの関係

## reference（参照元・編集しない）

- `travel-rate-camera-app-icon-selected-reference.png`（1254×1254）
  - 正式採用したアプリアイコンの参照画像。白地にタイルと落ち影が載ったモックアップ。
  - LPから直接は参照しない。正式アセットの切り出し元としてだけ使う。

## 正式Webアセット（LPが実際に使うもの）

すべて上の reference から**切り出し・角丸マスク・縮小だけ**で作った派生物（描き直し・生成はしていない）。

| ファイル | サイズ | 用途 |
| --- | --- | --- |
| `public/brand/app-icon-512.png` | 512×512・角透過 | ヘッダー／フッターのアイコン（next/image で縮小表示）、OGP画像のブランド欄 |
| `src/app/icon.png` | 192×192・角透過 | `<link rel="icon">`（Next.js のファイル規約） |
| `src/app/apple-icon.png` | 180×180・不透明 | `<link rel="apple-touch-icon">`。iOSは透過を黒で埋めるため、角はティール（#0E9488）で塗っている |
| `src/app/favicon.ico` | 16／32／48 | ブラウザのタブ |

## 切り出し条件（作り直すときに合わせる）

- タイルの範囲：x 154〜1098（幅945px）。縦はタイル中心（y≈618）に合わせた正方形
- 角丸マスク：半径 = 幅の24%、外周を3px内側へ寄せる（白地のにじみを残さないため）
- 縮小：LANCZOS

アイコンを差し替えるときは、reference を置き換えてから上の4ファイルを同じ条件で作り直す。
